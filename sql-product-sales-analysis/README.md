# SQL Product Sales Analysis

## Project Overview

This project uses Microsoft SQL Server to analyze product sales performance and transform transactional sales data into meaningful business metrics.

The project creates a product-level reporting view that supports revenue analysis, customer analysis, sales recency, and product performance segmentation.

## Tools & Technologies

- Microsoft SQL Server
- SQL
- Common Table Expressions (CTEs)
- Aggregate Functions
- Joins
- Window and date-related functions
- Business Intelligence and KPI analysis

## Data Sources

The project uses two tables from the Gold layer of a sales data warehouse:

- `gold.fact_sales` — sales transactions, order dates, quantities, and sales amounts.
- `gold.dim_products` — product names, categories, subcategories, and costs.

## Key SQL Concepts

- Common Table Expressions (CTEs)
- LEFT JOIN
- GROUP BY and aggregate functions
- COUNT DISTINCT
- DATEDIFF and GETDATE
- CASE expressions for business segmentation
- NULLIF for division-by-zero protection
- CREATE VIEW for reusable reporting logic

## Key Performance Indicators

| KPI | Description |
|---|---|
| Total Sales | Total sales revenue generated by each product |
| Total Orders | Number of distinct orders containing each product |
| Total Quantity | Total units sold |
| Total Customers | Number of distinct customers purchasing each product |
| Average Selling Price | Sales revenue divided by total quantity |
| Sales Recency | Months since the product's last recorded sale |
| Product Lifespan | Calendar-month difference between first and last recorded sales |
| Average Order Revenue | Product revenue divided by distinct orders containing it |
| Average Monthly Revenue | Product revenue divided by its measured lifespan, with a fallback for zero lifespan |

## Product Segmentation

Products are classified according to total sales:

- **High-Performer:** Total sales greater than 50,000
- **Mid-Range:** Total sales from 10,000 through 50,000
- **Low-Performer:** Total sales below 10,000

These thresholds are defined for this project and can be adjusted to fit the business context.

## Business Questions

This analysis helps answer questions such as:

1. Which products generate the highest sales revenue?
2. Which products attract the most customers?
3. Which products have not sold recently?
4. Which products are classified as high-, mid-, or low-performing?
5. What is the average selling price per unit?
6. How much revenue does each product generate per order?

## How to Use

1. Set up the source sales database and required Gold-layer tables.
2. Open the SQL scripts in SQL Server Management Studio (SSMS).
3. Execute the product report script to create the `gold.report_product` view.
4. Query the view to analyze product performance.

Example:

```sql
SELECT *
FROM gold.report_product
ORDER BY total_sales DESC;
```
